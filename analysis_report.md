# Sales Data Analysis Report

## 📌 Project Overview
This project is part of **Week 3: Introduction to Data Analysis**.  
It demonstrates how to use Pandas for:
- Loading and exploring datasets
- Cleaning data (missing values, duplicates)
- Performing statistical analysis
- Analyzing sales (total revenue, best product, average sales)
- Creating a recruiter‑friendly report
